# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting Vulnerabilities

If you discover a security vulnerability within Warborn Technologies projects, please do NOT open a public issue.

Instead, submit your report privately to our security team:
- **Security Contact**: `security@warborn.tech`
- **Acknowledgement**: Within 24 hours
- **Assessment & Triage**: Within 72 hours

## Disclosure Policy

- Please allow appropriate time for patch deployment before public disclosure.
- We follow coordinated vulnerability disclosure guidelines.
